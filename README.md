# 淘宝差评监控 · VOC

这是一个按视频结构复刻的淘宝差评监控演示原型，包含五个页签：

- 监控列表：维护淘宝/天猫商品链接、商品标签、店铺名、类目和启用状态
- 立即扫描：模拟页面采集流程，支持 CSV 或页面快照导入兜底
- VOC 表：查看中差评、追评、痛点、严重度和处理状态
- AI 报告：汇总高频痛点、严重预警、典型原文和改进清单
- 设置：维护采集页数、商品数、采集间隔、差评关键词和痛点分类

## 运行

```bash
npm run dev
```

然后打开：

```text
http://localhost:4173
```

也可以直接双击 `index.html`，核心功能会在浏览器本地运行。

## 淘宝页面采集说明

原型不绕过淘宝登录、验证码或平台限制。可选脚本只负责打开浏览器、等待你手动登录和定位评价区，然后保存页面快照：

```bash
npm install
npm run scrape:taobao -- "https://item.taobao.com/item.htm?id=商品ID"
```

保存后的文本快照可以粘贴到“立即扫描”的快照导入框中。
